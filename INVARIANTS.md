> Confirmed by David Schmidt 2026-07-20. switchyard is a **usage-aware dispatcher**

> rights to the Mac host. Threat model: **accident-containment, not adversary defense.**

## Stabilization policy

Task 0.1 begins a 20 reviewed integrated-change observation window. Until it closes, new routing policies, recovery automation, and compatibility branches are frozen. The only exceptions are security fixes and data-integrity-threatening defects; owner-authorized authentication renewal is separate authority, not an exception. An escaped defect is a defect introduced by an integrated qualifying change that escapes that change's required mapped automated gates. Parent-candidate reproduction is pre-existing: record it, but do not charge it to the candidate.

If the ledger schema, receipt semantics, or gate mapping changes, revalidate or exclude earlier rows. Exit requires zero recurrence of contract-loss, causal-overwrite, duplicate-terminal-count, missing-production-gate, or unobserved-postcondition defects; all relevant mapped gates run; no unexplained shadow mismatch; historical-defect mutations are killed; operational failures remain separately classified; and `recovery_required` items are empty or explicitly owner-disposed without consuming an execution slot. Provider success percentage is not the criterion; only the owner may unfreeze features. Worker-boot replay coverage is current, route-health enforcement remains disabled on the rollback VM path, and live Parallels activation gates remain separate. Local source/fixture work does not authorize credentialed provider calls, live VM mutation, roster change, external issue creation, push/publication, deployment, or irreversible legacy deletion.

rationale: The whole safety story. No working VM mounts the host filesystem or persistent host credentials — Parallels host-guest sharing is explicitly disabled for every managed VM. Agents operate only on the working VM's own copy of the code, seeded by `git archive` over the tar-transport seam (see `seedProjectWithBackend`), never a host bind mount. A host mount = the agent can nuke the Mac. OAuth and guest-keychain authentication is established once by a human **inside the golden VM image** as the non-admin `switchyard` account, then inherited by task clones where proven. OpenCode Go is the one runtime exception: a content-pinned BWS consumer injects exactly one API key into the fixed bridge, which deletes the broker variable and writes one bounded line only to the pinned `prlctl` child's stdin. The guest consumes that line before launch, rejects extra input, unsets its shell variable, and gives the provider EOF.
